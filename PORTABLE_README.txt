Bili Follower Tracker 0.3.0（B站粉丝变动助手 · Windows x64 便携版）
================================================

使用方法
--------
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 BiliFollowerTracker.exe。
3. 程序会打开一个终端窗口，并自动在默认浏览器打开本地页面。
4. 只输入 SESSDATA，点击“登录并检查粉丝变化”；程序会自动识别 UID、昵称和头像。
5. 关闭终端窗口即可停止程序。

本程序不安装 Python，不写入系统目录，也不创建系统服务。

本地数据
--------
快照和变化报告保存在程序目录下：

  .local-data\bilibili\<UP主UID>\

移动整个程序文件夹会同时移动历史数据。卸载时，先关闭程序，再删除整个
BiliFollowerTracker 文件夹即可。

网页历史只显示最新 99 份报告；更早的快照和报告仍保存在 .local-data 中，
不会自动删除。

安全说明
--------
- 本地服务只监听 127.0.0.1，不向局域网开放。
- SESSDATA 只在本次检查进程内使用，不写入快照或报告。
- 不要把 SESSDATA、程序数据目录或包含个人信息的截图发送给他人。
- “疑似取关”也可能来自账号注销、封禁或平台关系清理。
- 超过 1000 粉时，程序只报告通过关注时间排序和边界校验的可确认范围；
  位于第 1000 名边界之外或与边界时间相同的变化不会计入。

常见问题
--------
- 如果浏览器没有自动打开，请访问：http://127.0.0.1:8765/
- 如果端口被占用，请先关闭其他正在运行的本程序实例。
- Windows 可能对未签名程序显示 SmartScreen 提示；请只从可信发布来源下载，
  并核对发布页提供的 SHA-256 校验值。
