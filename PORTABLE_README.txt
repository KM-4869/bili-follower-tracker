Bili Follower Tracker 0.4.1（B站粉丝变动助手 · Windows x64 便携版）
================================================

使用方法
--------
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 BiliFollowerTracker.exe。
3. 程序会打开一个终端窗口，并自动在默认浏览器打开本地页面。
4. 点击“扫码并检查粉丝变化”，用手机 B 站 App 扫描二维码并确认。
5. 关闭终端窗口即可停止程序。

本次运行中，再次检查无需扫码。刷新网页也能继续使用已登录账号。
“切换账号”会清除内存中的旧凭证并重新扫码，不删除历史记录。

程序读取通讯录名单后，每次都会尝试用网页接口刷新最近最多 1000 人的
关注时间和关系，首次检查或名单没有变化时也一样。范围外保留历史资料。
自动刷新结果保存在本次新快照中；手动“补查状态”仍只更新当前页面。

本程序不安装 Python，不写入系统目录，也不创建系统服务。

本地数据
--------
快照和变化报告保存在程序目录下：

  .local-data\bilibili\<UP主UID>\

移动整个程序文件夹会同时移动历史数据。卸载时，先关闭程序，再删除整个
BiliFollowerTracker 文件夹即可。

网页历史只显示最新 99 份报告；更早的快照和报告仍保存在 .local-data 中，
不会自动删除。

安全说明
--------
- 本地服务只监听 127.0.0.1，不向局域网开放。
- access_key 和 SESSDATA 仅保存在本地进程内存，不写入文件或浏览器存储；关闭程序后需重新扫码。
- 不要分享有效登录二维码、程序数据目录或包含个人信息的截图。
- “疑似取关”也可能来自账号注销、封禁或平台关系清理。
- 通讯录翻页失败时，不替换原基线。正常读到末页但人数对不上时只提示，仍按实际名单比较。
- 旧基线只覆盖最近 1000 人时，升级后的首次报告不统计新增；旧历史文件原样保留。

常见问题
--------
- 如果浏览器没有自动打开，请访问：http://127.0.0.1:8765/
- 如果端口被占用，请先关闭其他正在运行的本程序实例。
- Windows 可能对未签名程序显示 SmartScreen 提示；请只从可信发布来源下载，
  并核对发布页提供的 SHA-256 校验值。
